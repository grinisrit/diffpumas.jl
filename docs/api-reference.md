# API Orientation

This is a practical map of the exported DiffPumas.jl API. It is not an
autogenerated reference; use it to find the right type or function, then inspect
docstrings and source for exact signatures when needed. Tomography-specific
names are exported by `DiffPumas.Tomography`; import that submodule explicitly
when using the full tomography surface.

## Top-Level Helpers

```julia
version()
pumas_info()
```

`version()` returns the package version constant. `pumas_info()` prints a short
human-readable package summary.

## Constants

Common exported constants:

- `ALPHA_EM`, `HBAR_C`, `BOHR_RADIUS`.
- `ELECTRON_MASS`, `MUON_MASS`, `TAU_MASS`.
- `PROTON_MASS`, `NEUTRON_MASS`, `PION_MASS`.
- `MUON_C_TAU`, `TAU_C_TAU`.
- `AVOGADRO_NUMBER`.

Example:

```julia
using DiffPumas

println("muon mass = $MUON_MASS GeV")
println("tau mass = $TAU_MASS GeV")
```

## Re-Exported Dependencies

DiffPumas.jl re-exports selected functions/types for convenience:

- Zygote: `gradient`, `pullback`, `jacobian`.
- PlotlyJS plotting constructors.
- TetGen: `tetrahedralize`, `RawTetGenIO`, `facetlist!`.
- TriangleIntersect: `Point`, `Ray`, `Triangle`, `Intersection`.

`TriangleIntersect.intersect` is imported but not exported to avoid conflicting
with `Base.intersect`.

## Stability Notes

The most user-facing APIs are:

- `create_physics`, `load_or_create_physics`, `get_material_index`.
- `property_range`, `property_stopping_power`, `property_kinetic_energy`.
- `compute_flux`, `compute_flux_uncertainty`.
- `compute_flux_differentiable_csda`, `compute_flux_gradient_csda`.
- `MaterialMixture`.
- Tomography forward-model helpers and solvers used by `examples/lvd_tomography.jl`.

Lower-level straggling, scattering, Turtle, and geometry internals are useful but
more likely to evolve as the research code changes.
