# Low-fraction pilot design review

The isolated driver uses new training and heldout angles, independent seed blocks, fixed geometric cell selection, immutable historical dry correction and a new two-coefficient material fit. Candidate coefficients are saved before validation. Control and candidate share identical heldout stochastic references, and derivatives compare matched-energy finite contrasts rather than substituting AD for stochastic transport derivatives. No production correction or manuscript is changed.

The first proposed analysis averaged per-replicate wet/dry ratios. Review identified that this changes the estimand through reciprocal/Jensen bias. The revised primary estimator is the ratio of replicate mean wet/dry fluxes; absolute flux uses model flux divided by mean reference flux. The first summary also applied absolute value to pseudovalues before averaging; this does not estimate absolute bias of the primary estimator. The revised summary computes the full absolute-bias change and applies delete-one jackknife only to its uncertainty.

These corrections precede any new draws. Full heldout-case completeness and replicate pairing checks were added. Remaining pilot gate: exact analysis of near-zero decision margins, derivative median improvement uncertainty, fixed-seed and invariant-model integrity checks, runnable bounded command and root convergence release. Any use of twice a jackknife SE is a descriptive screening convention; it supplies no coverage guarantee.

The deterministic `diagnose` mode and its proposed bounded command received PASS for execution on CPUs 8–15 with 16 GiB. It evaluates dry quadrature/domain only and returns before Monte Carlo draws or fitting. This is separate from pilot authorization.

Final pre-draw review resolves the statistical blockers: individual residual sign uncertainty is diagnostic only, all paired bias changes use the full statistic with delete-one jackknife uncertainty, and the stronger derivative median improvement requirement is explicitly declared as screening.
