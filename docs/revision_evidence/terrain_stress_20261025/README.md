# Predeclared localized terrain stress

This test uses the existing terrain model and observations. It cannot establish a measured terrain error, independent DEM agreement, or the actual cause of a residual sector. The ±1% and ±5% amplitudes are **assumed scenario scales**, not estimated errors or confidence bounds.

A smooth compact lens multiplies the original map-node height above the detector by `1 + a*sinpi((az-135)/45)^2*sinpi((zen-40)/15)^2` inside azimuth135–180° and zenith40–55°, and leaves nodes outside unchanged. Angles are computed from each node's original detector-relative coordinates. Rays are retraced against the modified surface, preserving the original600-cell volume and147-cell material support. All1003 covered directions, observations, frozen correction artifact, material properties, midpoint quadrature, pseudo-Huber scale, and absolute smoothness weight3.954930197858131 are held fixed. Surface exit height and remaining rock/air columns follow the retraced surface; in-volume water-segment lengths are not scaled indiscriminately. Any loss of covered rays fails closed. Bilinear interpolation can extend a small influence outside the analytic angular lens; the output records this rather than claiming exact directional confinement.

The preregistered design has six refits: zero and ±5% for each of the original690-bin screen and all1003 covered directions. Each starts at the same saved original field, uses100iterations and projected-gradient tolerance1e-6. Each stress must be compared to its **matching-screen zero continuation**, because the original field was nonstationary. The ±1% cases are forward-only diagnostics in each screen, declared before outcomes. The original screen retains only11 of34 covered sector directions, which motivates the all-direction comparison.

Before refits, the zero forward-only gate reproduced the original main objective100.59269073659428, projected-gradient infinity norm0.003311897033113187, and normalization3542719.29102373 **bitwise**, as well as path geometry and prediction. Its end audit reports successful completion and unchanged sources/runtime. The synthetic geometry regression passed31/31 checks. The generated cached primal is checked bitwise against uncached evaluation on each new path set; the historical cache certificate is not a certificate for the entire new terrain workflow.

`dev/run_terrain_stress.py` runs separate audited jobs in a serial queue with CPU0–7 and16GiB per-process address-space bounds. Its plan records source, core, dump, input and actual Julia binary identities and checks them before each case. Each job also audits unchanged sources/runtime and hashes its output. `dev/summarize_terrain_stress.py` compares fields and residuals to the matching zero, using all directions and sector/fit subsets. Non-KKT outcomes must be reported as finite-budget solver outcomes, not converged sensitivity or uncertainty bounds.

The durable queue was launched in tmux `terrain_stress_20261025`; results are under `examples/data/terrain_stress_20261025`. At preparation time the numerical refits were running; no terrain-sensitivity result is claimed by this design record. The original baseline and all historical correction/source bindings remain untouched.
